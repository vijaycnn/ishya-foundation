# Ishya Foundation (Next.js)

This folder is the Ishya Foundation website converted from Create React App to **Next.js 16** (App Router).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm start` — serve the production build
- `npm run lint` — run ESLint

Open [http://localhost:3000](http://localhost:3000) after `npm run dev`.

The original CRA backend calls still point to `http://localhost:3001`.
